# ゲーム制作計画（PLAN）

スイッチスポーツのバレーボール風 2vs2 インドアバレーゲーム。HTML + three.js(CDN) のみ。

## ゴール
- `index.html` をブラウザで開くだけで動く（file:// でも動くよう ES Modules は使わず classic script + 名前空間 `SV`）
- 開いた瞬間から AI 同士のデモプレイ。見どころ（スーパースパイクのスロー演出 → 得点 → 勝利演出）まで自動で到達
- キーボード / スマホ仮想キーで人間がプレイ可能
- 内部解像度 1280x720（HD）固定、ウィンドウに合わせて 16:9 でスケール
- キャラ・会場・ボール・効果音は全てコードで生成（Canvas テクスチャ / WebAudio 合成）

| `js/character.js` | プリミティブで組んだ人型キャラ（トゥーン＋輪郭線、アニメ風の顔、髪型）+ ポーズブレンドの手続きアニメ |

| `js/ball.js` | ボール物理（重力、バウンド、ネット衝突、軌跡、着地予測） |

## ゲームの仕組み（要点）
- 座標: m 単位。ネットは z=0、手前（z>0）が自チーム(青)、奥が相手(赤)。x がコート幅方向
- ボールの打ち返しは「目標地点 + 滞空時間」から初速を逆算 → 狙った所に必ず届く。タイミング精度で誤差を加える
- 各打球後、受ける側で「接触予定点（ボールが接触高さに下降する位置と時刻）」を計算し担当者を割り当てる
- 人間はその接触時刻に対してボタンを押すタイミングで成否・質が決まる（PERFECT / GOOD / OK / MISS）
- 3段攻撃: レシーブ担当 → もう一人がトス → レシーバーがアタッカー。アタック時は相手前衛がブロック
- 移動は自動（スイッチスポーツ同様）。方向キーで手動補正 / アタック・サーブ時は狙う方向
