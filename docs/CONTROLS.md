# 操作方法

起動するとデモプレイ（AI 同士）が始まります。何かキーを押すかタップするとタイトル→試合開始。

## キーボード
| キー | 動作 |
|---|---|
| ← → ↑ ↓ / WASD | 移動（基本は自動移動。押すと手動で補正）。サーブ・スパイク時は狙う方向 |
| Space / J / Z | アクション（状況で変化：レシーブ・トス・スパイク・ブロック・サーブ） |
| Enter | 試合開始 / リトライ |
| P / Esc | ポーズ |
| M | 音声 ON/OFF |

## アクションの中身
- **サーブ**: 1回押すとトス、ボールが一番高い所でもう1回押して打つ（ジャストでジャンプサーブ）
- **レシーブ / トス**: ボールが自分に届く瞬間（足元の輪が縮みきった時）に押す
- **スパイク**: トスが上がったら押してジャンプ → 空中でボールに触れる瞬間にもう一度押す。ジャストで「スーパースパイク」
- **ブロック**: 相手がスパイクを打つ直前に押すとジャンプしてブロック（ネット際にいる時）

## スマホ
画面左下の十字キー = 移動 / 狙い、右下の A ボタン = アクション、右上 Ⅱ = ポーズ、♪ = 音声。
横向き推奨。
